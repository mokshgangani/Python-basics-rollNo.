# python-basics-RollNo

This repository contains basic C++ programs created for practice and GitHub activity tasks.

## Programs Included

### 1. factorial.cpp
- **Purpose:** Calculates the factorial of a given number using recursion.  
- **Concepts Used:** basics loops and variable initilization
- **Example:** Input `5` → Output `120`.

### 2. fibonacci.cpp
- **Purpose:** Generates the Fibonacci sequence up to a specified number of terms.  
- **Concepts Used:** Recursion and sequence generation.  
- **Example:** Input `6` → Output `0 1 1 2 3 5`.
